# Backlog hoãn — Quản lý dữ liệu và báo cáo
Trạng thái: DEFERRED. Chỉ phân rã thành task khi ba module ưu tiên đã tích hợp ổn định và module Quality/Cost được xử lý theo ưu tiên của nhóm.
Nguồn tham khảo: `docs/ERP_Nhom5.docx`.
## Đúng 5 nhóm chức năng để lập task chi tiết sau
1. Quản lý danh mục dữ liệu.
2. Tra cứu dữ liệu.
3. Tạo báo cáo.
4. Xem và phân tích báo cáo.
5. Xuất báo cáo.
## Ranh giới dự kiến
Báo cáo đọc qua API/read model có quyền, không sửa dữ liệu sở hữu bởi HR, Kho, Sản xuất hoặc Quality/Cost. Chưa tạo task triển khai, migration hay giao diện trong giai đoạn hiện tại.
