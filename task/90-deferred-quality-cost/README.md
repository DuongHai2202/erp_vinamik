1. Kiểm tra chất lượng thành phẩm.
2. Xử lý sản phẩm không phù hợp.
3. Tính giá thành sản phẩm.
4. Đề xuất/ra quyết định điều chỉnh giá bán.
5. Phê duyệt bảng giá.
